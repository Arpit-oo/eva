PROBLEM STATEMENT

Solopreneurs and small brands spend hours creating content for multiple social platforms. Build a SaaS
where a user inputs their brand voice and niche, and the AI generates a full week of social media content
(posts, captions, hashtags, image suggestions) across platforms, with a built-in scheduling calendar.
MVP FEATURES (Must Build)

    User auth + brand profile setup (niche, tone, target audience, brand keywords)
    AI content generation: generate 7 days of posts for at least 2 platforms (Twitter/X, LinkedIn,
    Instagram)
    Each generated post includes: caption text, relevant hashtags, image prompt or suggestion, best
    posting time
    Content calendar view (week and month) to organize and schedule posts
    Edit and regenerate individual posts before publishing
    Content library to save and reuse top-performing templates

BONUS FEATURES (If Time Permits)

* Direct publishing to Twitter or LinkedIn via API
* AI image generation for post visuals using the image prompts
